# Code of conduct

We follow the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

In short: be respectful, assume good faith, no harassment, no personal attacks, no sharing of other people's private data.
Maintainers may hide, edit or remove contributions that break these rules and may block repeat offenders.

Report conduct problems privately to the contact shown on the giuggiai organization profile on GitHub (not through security reports or public issues).
