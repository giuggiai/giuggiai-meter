# Security policy

Please **do not** report security problems in public issues.

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository.
If that is not available to you, write to **oss@giuggiai.com** with the subject `SECURITY giuggiai-meter`.
We acknowledge reports within 72 hours and keep you informed until a fix is released.

Supported versions: the latest release only.
